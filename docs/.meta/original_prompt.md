# 原始需求 Prompt（存档）

> 存档时间：2026-08-20 16:21 (GMT+8)
> 来源：用户 `/pm` 指令输入，未经修改。

---

使用go语言实现一个基于 Git 原理的简易版本控制系统，需要带一个前端管理页面

具体功能：
- 核心对象管理：实现 Git 的三大对象（Blob 存储内容、Tree 存储目录结构、Commit 存储提交信息），并使用 SHA-1/SHA-256 压制哈希键。
- 暂存区与提交：实现类似 add（写入暂存区 index 文件）和 commit（生成快照树）的功能。
- 分支管理：实现 branch 的创建、切换（修改 HEAD 指针）以及基础的 merge（三方合并算法）。
- 存储压缩：使用 zlib 对对象文件进行压缩存储。
