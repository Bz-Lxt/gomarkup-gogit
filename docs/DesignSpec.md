# GoGit Design Spec — Carbon Archive

> 日期：2026-08-20 (GMT+8)
> 美学方向：**Carbon Archive**（碳层档案室）
> 不是又一个紫渐变仪表盘。界面应像一座保存胶片与铅字的地下档案库：石墨、黄铜、单色灯箱。

---

## 1. 概念

GoGit 管理的是「对象」与「指针」。视觉语言围绕 **档案抽屉 / 灯箱 / 铅字哈希** 展开：

- 背景是深石墨，带极弱胶片颗粒，不是纯黑。
- 强调色是陈年黄铜，只出现在当前分支、主按钮、时间轴节点。
- 哈希永远是等宽冷青，像灯箱上的编号。
- 信息密度中等偏高：档案员需要一眼看到 HEAD、暂存数量、冲突。

## 2. 调色板

| Token | Hex | 用途 |
|---|---|---|
| `--bg` | `#0c0e12` | 页面底 |
| `--bg-elev` | `#141820` | 侧栏 / 卡片 |
| `--bg-sunken` | `#090b0e` | 代码井 / 对象查看 |
| `--line` | `#2a3140` | 边框 |
| `--brass` | `#c9a227` | 主强调、当前态 |
| `--brass-dim` | `#8a7018` | hover 阴影 |
| `--cyan` | `#7ec8c4` | 哈希、链接 |
| `--ink` | `#e8e4d9` | 主文字（热纸色，避免纯白） |
| `--muted` | `#8b907c` | 次级文字 |
| `--danger` | `#d45d4c` | 冲突 / 删除 |
| `--ok` | `#7aaf6a` | 已暂存 / 成功 |

禁止：紫色渐变、纯白卡片、Inter / Roboto / Arial / Space Grotesk。

## 3. 字体

- **Display**：Syne（700/800）— 标题「GoGit」、视图名
- **Body**：Source Serif 4（400/600）— 说明文字、提交信息
- **Mono**：IBM Plex Mono — 哈希、路径、冲突标记

Google Fonts 引入，`html` 根字体 15px。

## 4. 布局

- **左轨 252px**：仓库身份、六视图导航、HEAD 缩略。`768px` 以下改为顶部横滑导航，侧栏隐藏。
- **主区 `w-full`**：禁止页面级 `max-w-*`。内边距 `24px`（手机 `16px`）。
- **顶栏**：当前分支黄铜徽章 + 对象计数 + 哈希算法。
- **480px**：卡片单列、表格横向滚动、文件树缩进减小。

## 5. 组件

### 按钮
- Primary：黄铜底、石墨字、2px 实边、hover 上移 1px。
- Ghost：透明 + 黄铜描边。
- Danger：赤陶描边，不铺满红底。

### 输入
- 沉底背景 `--bg-sunken`，聚焦时黄铜 1px ring。
- 全局 `select` 自定义箭头（折线 SVG，`#999`，12×8），`appearance: none`，`padding-right: 36px`。

### Toast
- 右下角滑入。可点 × 关闭，5s 自动消失。成功/失败分色。

### Modal
- 禁止 `alert/confirm`。居中档案卡片，遮罩 60% 石墨 + blur。危险操作必须确认。

### 哈希芯片
- 等宽 7 位短哈希，hover 显示全文，点击复制。

### 状态徽标
- staged = 黄铜、modified = 赤陶、untracked = 冷青、deleted = 空心赤陶。

### 提交时间轴
- 左侧黄铜竖线 + 圆点。点选展开 tree 快照。时间格式 `yyyy-MM-dd HH:mm:ss`。

### 冲突井
- 等宽、沉底。`<<<<<<<` 赤陶，`=======` 黄铜，`>>>>>>>` 冷青。

## 6. 动效

- 首屏：侧栏与主卡片 `translateY(8px)` + fade，stagger 60ms。
- 视图切换：主区 160ms fade，不做路由闪白。
- 禁止大面积无限循环动画。颗粒背景为静态 CSS noise。

## 7. 六视图

1. **总览** — 统计磁贴 + 最近 5 次提交。
2. **工作区** — 文件树、内容预览、新建/保存/删除。
3. **暂存区** — index 表 + status 三栏 + add / commit 表单。
4. **历史** — 分支筛选时间轴 + 快照。
5. **分支** — 列表、创建、切换、merge、冲突报告。
6. **对象** — 哈希检索 Blob/Tree/Commit 解析视图。

## 8. 交互规则

- 所有写操作按钮必须绑定真实 API；无功能入口一律不放。
- 提交信息、分支名、文件路径在提交前校验，错误红字写在字段下方。
- 切换分支 / 删除文件 / merge 走确认 Modal。
- 列表进详情：提交点击展开快照；对象检索展示解析结果。
